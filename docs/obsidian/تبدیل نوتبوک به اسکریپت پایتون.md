# 🛠️ تبدیل نوتبوک به اسکریپت پایتون

**تگ‌ها:** #مفهوم #پایتون #اسکریپت #اتوماسیون

---

## ۱. این مفهوم چیست؟
نوتبوک‌های ژوپیتر (فایل‌های `ipynb.`) محیطی برای تست، آزمون و خطا و یادگیری هستند. وقتی کد نهایی شد، کدهای اصلی را کپی کرده و داخل یک فایل ساده پایتون (مثلاً `sales_analysis.py`) با استفاده از توابع (Functions) بازنویسی می‌کنیم.

## ۲. چرا به آن نیاز داریم؟
نوتبوک‌ها برای اجرای اتوماتیک و زمان‌بندی شده (مثلاً اجرای هر روز ساعت ۸ صبح) مناسب نیستند. کدهای تجاری و سازمانی (Production) باید در قالب اسکریپت‌های پایتون باشند تا به راحتی توسط سیستم‌ها اجرا شوند.

## ۳. چه مشکلی را حل می‌کند؟
در نوتبوک شما ممکن است یک سلول را سه بار اجرا کنید یا سلول‌ها را جابجا اجرا کنید. این کار باعث می‌شود اجرای کد برای بقیه سخت شود. یک فایل اسکریپتِ مبتنی بر تابع (Function)، جریان برنامه را از بالا به پایین منظم و قابل پیش‌بینی می‌کند.

## ۴. سینتکس و نحوه استفاده چگونه است؟
به جای کدهای پراکنده، تمام منطق را داخل توابع دسته‌بندی می‌کنیم:
```python
def load_data(file_path):
    return pd.read_excel(file_path)

def clean_data(df):
    df = df.drop_duplicates()
    # بقیه کارهای تمیزکاری
    return df

if __name__ == "__main__":
    raw = load_data("data/raw/sales_data.xlsx")
    clean = clean_data(raw)
    clean.to_excel("data/processed/clean.xlsx", index=False)
```

## ۵. در این پروژه چطور از آن استفاده می‌کنیم؟
در آخرین مرحله کدنوسی پروژه، ما باید کدهای بدردبخور دو نوتبوک Cleaning و Analysis را برداریم، آن‌ها را داخل فایل `src/sales_analysis.py` در قالب چند تابع تمیز و خوانا مرتب کنیم تا هر ماه که فایل فروش جدید می‌آید، فقط با یک کلیک کل مراحل انجام شود.

## ۶. چه اشتباهات رایجی را نباید انجام دهیم؟
- **کپی کردن کورکورانه:** از کپی کردن تمام دستورات نمایشی مثل `df.head()` یا `df.info()` در اسکریپت نهایی خودداری کنید. اسکریپت نهایی فقط جای کدهایی است که تغییر و پردازش روی داده‌ها انجام می‌دهند، نه کدهایی که صرفاً برای نمایش به چشم انسان نوشته شده‌اند.

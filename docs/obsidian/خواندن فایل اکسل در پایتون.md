# 📥 خواندن فایل اکسل در پایتون (pd.read_excel)

**تگ‌ها:** #مفهوم #پانداس #اکسل #ورودی_داده

---

## ۱. این مفهوم چیست؟
تابع `read_excel` یکی از ابزارهای کتابخانه Pandas است که به ما اجازه می‌دهد مستقیماً یک فایل اکسل (xlsx. یا xls.) را بخوانیم و محتویات آن را تبدیل به یک [[Pandas DataFrame]] کنیم.

## ۲. چرا به آن نیاز داریم؟
پایتون به صورت پیش‌فرض نمی‌تواند فایل‌های اکسل را بخواند. برای اینکه بتوانیم روی داده‌های خام یک شرکت (که معمولاً در اکسل ذخیره می‌شوند) پردازش انجام دهیم، اول باید آن‌ها را وارد محیط پایتون کنیم.

## ۳. چه مشکلی را حل می‌کند؟
بدون این تابع، خواندن داده‌های اکسل نیازمند نوشتن ده‌ها خط کد پیچیده برای باز کردن فایل‌های باینری و استخراج خانه‌ها بود. این تابع با یک خط کد، تمام ساختار جدول، سطرها و ستون‌ها را مرتب وارد برنامه می‌کند.

## ۴. سینتکس و نحوه استفاده چگونه است؟

```python
import pandas as pd

# مسیر فایل رو بهش میدیم
df = pd.read_excel("data/raw/sales_data.xlsx", sheet_name="Raw_Sales_Data")

# حالا کل جدول تو متغیر df ذخیره شده
```

## ۵. در این پروژه چطور از آن استفاده می‌کنیم؟

در اولین قدم نوتبوک `01_data_inspection.ipynb` ما فایل `sales_data.xlsx` رو که داده‌های خام فروش شرکته، با استفاده از همین دستور خوندیم و ریختیم تو متغیر `df` تا بتونیم بررسیش کنیم.

## ۶. چه اشتباهات رایجی را نباید انجام دهیم؟

- **خطای مسیر فایل (FileNotFoundError):** رایج‌ترین اشتباه اینه که آدرس فایل رو اشتباه بدیم. همیشه بهتره از مسیرهای نسبی (Relative Path) نسبت به ریشه پروژه استفاده کنیم، نه مسیر مطلق (`C:/...`) تا اگر پروژه رو روی سیستم دیگه‌ای بردیم هم کار کنه.
- **نصب نبودن openpyxl:** پانداس برای خوندن فایل‌های مدرن اکسل به کتابخانه `openpyxl` نیاز داره. اگر نصب نباشه ارور میده.

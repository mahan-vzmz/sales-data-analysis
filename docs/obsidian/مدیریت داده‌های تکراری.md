# 👯‍♂️ مدیریت داده‌های تکراری (Duplicates)

**تگ‌ها:** #مفهوم #پانداس #پاکسازی_داده

---

## ۱. این مفهوم چیست؟
ردیف‌های تکراری، سطرهایی در جدول هستند که تمام یا بخشی از مقادیر آن‌ها کاملاً شبیه به یک سطر دیگر است. توابع `duplicated` و `drop_duplicates` برای مدیریت این موارد استفاده می‌شوند.

## ۲. چرا به آن نیاز داریم؟
هنگام ذخیره یا ترکیب داده‌ها در دیتابیس‌ها و فایل‌های اکسل، معمولاً پیش می‌آید که یک سفارش اشتباهاً دو بار ثبت شود. 

## ۳. چه مشکلی را حل می‌کند؟
اگر سطرهای تکراری را حذف نکنیم، در محاسبات مالی و KPIs ما اختلال ایجاد می‌شود. مثلاً درآمد یک سفارش دو بار جمع زده می‌شود و سود کل شرکت به اشتباه بیشتر از واقعیت گزارش می‌شود.

## ۴. سینتکس و نحوه استفاده چگونه است؟
برای پیدا کردن تکراری‌ها:
```python
# نمایش True برای سطرهایی که تکراری هستند
df.duplicated()

# شمارش تعداد کل سطرهای دقیقاً تکراری
df.duplicated().sum()
```

برای حذف آن‌ها (در مراحل بعد):
```python
# حذف تکراری‌ها و ذخیره دیتافریم جدید
df = df.drop_duplicates()
```

## ۵. در این پروژه چطور از آن استفاده می‌کنیم؟
در نوتبوک بازرسی داده، ما با استفاده از `df.duplicated().sum()` متوجه شدیم که دقیقاً ۸ سطر در فایل فروش ما کاملاً تکراری هستند. 

## ۶. چه اشتباهات رایجی را نباید انجام دهیم؟
- **حذف بدون بررسی:** قبل از استفاده از `drop_duplicates()` حتماً باید مطمئن شوید که آیا واقعاً کل ردیف تکراری است یا فقط یک شناسه تصادفاً تکرار شده؟ اگر دو مشتری در یک روز یک محصول را با یک قیمت خریده باشند، ممکن است شبیه داده تکراری به نظر برسند، به همین دلیل معمولاً کل سطر یا `Order_Line_ID` بررسی می‌شود.
- **فراموش کردن آپدیت متغیر:** تابع `drop_duplicates` خودش جدول اصلی را تغییر نمی‌دهد، بلکه یک کپی از آن برمی‌گرداند. پس همیشه باید آن را به یک متغیر جدید (یا همان `df`) نسبت دهید: `df = df.drop_duplicates()`

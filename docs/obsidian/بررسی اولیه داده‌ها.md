# 🕵️ بررسی اولیه داده‌ها (Data Inspection)

**تگ‌ها:** #مفهوم #پانداس #بازرسی_داده

---

## ۱. این مفهوم چیست؟
مجموعه‌ای از توابع در پانداس هستند که برای نگاه کردن به شکل، ساختار و آمار کلی یک [[Pandas DataFrame]] استفاده می‌شوند. شامل:
- `head()` و `tail()`: دیدن چند سطر اول و آخر
- `shape`: گرفتن ابعاد جدول (تعداد سطر و ستون)
- `columns`: دیدن اسم ستون‌ها
- `dtypes`: دیدن نوع داده‌ی هر ستون (متن، عدد، تاریخ)
- `info()`: خلاصه ساختار جدول و تعداد داده‌های خالی
- `describe()`: آمار ریاضی ستون‌های عددی (میانگین، مینیمم، ماکزیمم و...)

## ۲. چرا به آن نیاز داریم؟
وقتی یک فایل بزرگ با هزاران سطر رو وارد پایتون می‌کنیم، نمی‌تونیم همه‌ش رو با چشم ببینیم (مثل محیط اکسل). این دستورات به ما دید کلی و سریع نسبت به داده‌ها می‌دن.

## ۳. چه مشکلی را حل می‌کند؟
جلوگیری از کارهای کورکورانه! قبل از هرگونه پاکسازی یا تحلیل، باید بدونیم با چه چیزی طرفیم. مثلاً اگر بدونیم فلان ستون از نوع متنی (Object) است در حالی که باید عدد باشه، می‌فهمیم که نیاز به تبدیل نوع داده داریم.

## ۴. سینتکس و نحوه استفاده چگونه است؟

```python
# ۵ سطر اول جدول رو نشون میده
df.head()

# ابعاد جدول رو میگه مثلا (1295, 11) یعنی 1295 سطر و 11 ستون
df.shape

# اطلاعات کلی و نوع داده‌ها
df.info()

# آمار توصیفی (مثل میانگین قیمت‌ها)
df.describe()
```

## ۵. در این پروژه چطور از آن استفاده می‌کنیم؟
در نوتبوک اول (`01_data_inspection.ipynb`) از تک تک این دستورات استفاده کردیم تا با داده‌های خاممون آشنا بشیم. فهمیدیم ۱۲۹۵ سطر داریم، قیمت‌ها چقدر نوسان دارن و چه ستون‌هایی داریم.

## ۶. چه اشتباهات رایجی را نباید انجام دهیم؟
- **پرینت کردن کل دیتافریم:** سعی نکنید کل `df` رو یکجا پرینت کنید چون اگر داده بزرگ باشه هم کامپیوتر هنگ میکنه هم خوندنش غیرممکنه. همیشه از `head()` استفاده کنید.
- **اعتماد چشم‌بسته به `describe`:** این تابع فقط روی ستون‌هایی کار می‌کنه که پانداس اونا رو عدد شناخته باشه. ممکنه یک ستون عددی به خاطر وجود یه حرف توش، به عنوان متن شناخته شده باشه و اینجا نیاد.

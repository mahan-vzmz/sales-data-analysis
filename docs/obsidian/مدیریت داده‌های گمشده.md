# 👻 مدیریت داده‌های گمشده (Missing Values / NaNs)

**تگ‌ها:** #مفهوم #پانداس #پاکسازی_داده

---

## ۱. این مفهوم چیست؟
گاهی در جداول داده، برخی سلول‌ها خالی هستند. در پانداس این سلول‌های خالی با مقدار `NaN` (Not a Number) یا `None` نمایش داده می‌شوند. بررسی و رفع آن‌ها را مدیریت داده‌های گمشده می‌گویند.

## ۲. چرا به آن نیاز داریم؟
داده‌های دنیای واقعی هیچ‌وقت بی‌نقص نیستند. ممکنه کاربر یادش رفته باشه شهری رو وارد کنه، یا سیستم خطا داده باشه و مقداری ثبت نشده باشه. 

## ۳. چه مشکلی را حل می‌کند؟
وجود `NaN` در داده‌ها باعث خطاهای محاسباتی می‌شه. مثلا اگر بخواهید میانگین فروش رو حساب کنید و بین اعداد `NaN` باشه، ممکنه نتیجه کلا خراب بشه یا ارور بگیرید. 

## ۴. سینتکس و نحوه استفاده چگونه است؟
برای پیدا کردن داده‌های گمشده:
```python
# آیا هر سلول خالی است یا نه؟ (خروجی True/False)
df.isna()

# جمع زدن تعداد True ها در هر ستون (برای اینکه ببینیم هر ستون چندتا خالی داره)
df.isna().sum()
```

برای مدیریت آن‌ها (در مراحل بعد):
```python
# حذف کل سطرهایی که مقدار خالی دارند
df.dropna()

# پر کردن مقادیر خالی با یک کلمه جایگزین
df["City"] = df["City"].fillna("Unknown")
```

## ۵. در این پروژه چطور از آن استفاده می‌کنیم؟
در نوتبوک `01_data_inspection` با دستور `df.isna().sum()` فهمیدیم که ستون City ده تا جای خالی داره و ستون Payment_Method هم ۸ تا. این به ما هشدار داد که در فاز پاکسازی باید فکری به حالشون بکنیم.

## ۶. چه اشتباهات رایجی را نباید انجام دهیم؟
- **استفاده بی‌رویه از `dropna()`:** بدترین اشتباه اینه که هرجا داده خالی دیدیم، سریع کل اون سطر رو پاک کنیم (`dropna`). با این کار ممکنه داده‌های باارزش بقیه ستون‌های اون سطر رو از دست بدیم. اول باید بررسی کنیم ببینیم چرا داده خالیه و آیا میشه با روش دیگه‌ای (مثلا جایگذاری با عدد 0 یا کلمه Unknown) مشکل رو حل کرد؟
